# 2026-UCAS-DM-note-zjt

这是一个用于整理和分享 **中国科学院大学（UCAS）2026学年《离散数学》课程** 个人学习笔记、理论证明与算法分析的开源仓库。

本课程紧密结合计算机科学应用（被誉为“计算机科学的微积分”），不仅涵盖抽象的数学结构，更侧重于各种图论、数论与计数算法的推导与时间复杂度分析。

## 📝 笔记核心模块

本笔记根据教学大纲，深入提炼并记录了以下各大核心领域的数学理论及其实际计算算法：

1. **关系与偏序**：
   - 关系的运算、表示方法与闭包性质。
   - 传递闭包的计算原理与 **Roy-Warshall 算法**。
   - 偏序关系、全序与良序集、字典序、哈斯图（Hasse Diagrams）极值分析、上/下界判定以及**拓扑排序（Topological Sorting）**。

2. **图论（Graph Theory）**：
   - 图的基本术语、邻接与度数、子图操作；二分图判定、匹配问题与 **Hall 婚姻定理**。
   - 连通性分析（无向图/有向图的连通度及顶点连通度）。
   - 带权图最短路径算法（**Dijkstra 算法**与 **Floyd-Warshall 算法**）。
   - 欧拉回路与欧拉路径（**Fleury 算法**）、哈密尔顿回路（旅行商问题 TSP 基础）。
   - 平面图判定、面与欧拉公式、**库拉托夫斯基定理（Kuratowski's Theorem）**。
   - 图着色与色数计算、无向树、决策树的应用。

3. **命题与谓词逻辑（数理逻辑）**：
   - 命题逻辑语法、语义（真值指派与真值表）、翻译与系统规约。
   - 语义等价性（基本逻辑等价定律、条件/双条件等价、CNF 与 DNF 范式转换）。
   - 可满足性问题（SAT）与 **SMT 求解器**（以数独谜题编码求解为例）。
   - 推理规则（基本推理、归结原理与经典证明）。
   - 谓词逻辑：量词（全称/存在）、自由变量与约束变量、嵌套量词顺序、语义等价变换、涉及量词的推理规则及**前束范式（Prenex Normal Form, PNF）**。

4. **证明方法与策略**：
   - 正式与非正式证明、基本证明方法（直接证明、逆反证明、反证法、分情况证明）。
   - 经典逻辑谬误分析（无效推理、循环论证）。
   - 正向与反向推理策略（以 **Nim 游戏** 分析为例）、证明改编。
   - 等价性与存在性证明、多米诺与三联骨牌染色铺砖问题。
   - 开放数学问题的作用（费马大定理、考拉兹猜想）。

5. **数论（Number Theory）**：
   - 整除性、带余除法与模运算；最大公约数、**贝祖定理（Bézout’s Theorem）**与素因子分解。
   - 素性测试与素数分布：埃拉托色尼筛法、试除法素性测试、素数定理。
   - **欧几里得算法与扩展欧几里得算法**（贝祖系数求解及复杂度分析）。
   - 线性同余方程、模逆元；**中国剩余定理（Chinese Remainder Theorem）及回代法**。
   - 计算机大整数算术的剩余表示法。
   - 费马小定理、原始根与离散对数。
   - 数论应用：哈希函数、伪随机数生成（线性同余法）、校验码技术（ISBN 校验与错检能力分析）。

6. **高级计数技巧**：
   - 递推关系建模：斐波那契、汉诺塔、归并排序、卡特兰数与括号化问题。
   - 线性齐次/非齐次递推关系求解（特征方程、重根、高阶重根完整刻画、待定系数法求特解）。
   - 分治递推关系（二分搜索、最大最小值、归并排序、快速整数/矩阵乘法复杂度分析）、迭代展开法与**主定理（Master Theorem）**。
   - 分治快速算法应用：**最近点对问题（Closest-Pair Problem）**的四阶段算法及复杂度分析。
   - **生成函数（Generating Functions）**：形式幂级数基本运算、闭形式、扩展二项式定理、卡特兰数的生成函数解法。
   - **广义容斥原理**：一般表述与补集形式、埃氏筛完整计算、满射函数数量计算、错位排列（Derangements）。
